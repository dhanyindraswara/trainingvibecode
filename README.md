## Cara pakai

| Aksi | Tombol |
|------|--------|
| Slide berikutnya | `→` `spasi` atau klik sisi kanan layar |
| Slide sebelumnya | `←` atau klik sisi kiri layar |
| Lihat semua slide | `O` |
| Layar penuh | `F` |
| Di HP | geser kiri / kanan |
